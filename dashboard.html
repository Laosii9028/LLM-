存回 repo

在這裡的修改只在瀏覽器內。下載更新後的檔案,覆蓋回你的 repo 並 push,變更才會生效。

1

一鍵直接觸發

貼上 fine-grained GitHub token,權限只需要這個 repo 的 Actions: read/write。token 不會寫進 repo。

尚未觸發
提醒: GitHub Pages 是靜態網頁,不能安全地內建私密金鑰。請建立只限此 repo、只開 Actions read/write 的 fine-grained token,並只在自己的裝置使用。
2

在本機執行

設好三個環境變數後,在專案資料夾執行:

python main.py
